# Local AH Flipper

Personal Fabric 26.1.2 auction scanner. It uses Hypixel's keyless bulk auction endpoint and decodes the `item_bytes` NBT to compare an item only with auctions carrying the same significant modifiers. It asks Cofl's public NBT pricing endpoint for historical sales volume only after a listing passes the local profit checks. No Cofl account, API key, Cofl mod, or separate background service is required.

The first successful scan establishes a baseline. Later scans alert only for newly seen BIN auctions with at least three older, distinct-seller comparable listings. The estimated resale price is capped by the lowest comparable current asking price. The mod also records actual BIN sales from Hypixel's public ended-auctions feed in `config/local-ah-flipper-sales/` and uses a conservative recent sale price once it has at least five sales from three sellers for that exact item variant. With no sale history yet, the estimate uses asking prices only. Inspect every auction before buying.

`/localflip status`, `/localflip on`, `/localflip off`, `/localflip reload`, and `/localflip scan` are available in game. Config lives in `.minecraft/config/local-ah-flipper.json` after first launch. A flip passes either profit rule: at least 500k estimated profit **and** 25% estimated profit relative to cost, **or** at least 1.5m estimated profit **and** 10% estimated profit relative to cost. `maxCost: 0` means no cost cap. The scanner follows the 60-second auction refresh cadence and runs only while connected to a `hypixel.net` server. Profit includes a conservative 5% resale allowance before the minimum profit checks. Flip alerts use Minecraft dark purple (`§5`) for the label, item name, and profit.

The saved Cofl blacklist is reproduced as one AND rule: block an item only when it is both recombobulated and an accessory. The mod reads `rarity_upgrades` from the item's NBT and classifies accessories with Hypixel's public item-resource data. It ships a current accessory list and refreshes it at startup; set `blockRecombobulatedAccessories: false` to disable this rule.

`minDailySales: 3` uses Cofl's historical, modifier-aware volume returned for the candidate's actual auction NBT. If Cofl returns a median for the exact item key it chose, that historical price can only lower the local resale target, and the profit rules are checked again. The request runs asynchronously, so it does not block parsing the rest of the Hypixel snapshot; successful estimates are cached for 10 minutes per exact local item variant. The first uncached match waits for the Cofl response before it can alert. Observed responses were about 0.2–0.8 seconds. The mod keeps well below Cofl's published public rate limits. If that service is unavailable or its request budget is exhausted, it falls back to local sales/day only after recording at least 98% of the previous 24 hours of Hypixel's ended-auction feed. Otherwise it still alerts and labels volume `unverified` rather than silently losing a possible snipe. `/localflip status` shows the local coverage and Cofl lookup counts. The three older distinct-seller comparable listings remain required regardless of volume. The saved Cofl Bazaar whitelist applies to buy-order/sell-order opportunities, not Auction House listings, and is outside this AH-only mod.

The active-auction scanner uses the API's `Last-Modified` and `Date` headers to predict the next public snapshot. It checks shortly before that boundary, retries conditional page-0 requests every 350 ms for eight seconds if the snapshot has not changed, then checks every two seconds until it does. As page 0 streams in, it checks new BINs against the previous full snapshot and can start the volume lookup before the page finishes downloading. Six workers then fetch and decode the remaining pages. The sold-auction reference feed still runs every 30 seconds. The log reports first-candidate, page-0, and full-scan times. Hypixel's public feed can lag actual auction creation, so this minimizes delay after publication but cannot provide true pre-API alerts or guarantee a subsecond alert from the listing time.

Build with JDK 25 and `gradlew.bat build`. The artifact is `build/libs/LocalAhFlipper-0.1.0.jar`.
